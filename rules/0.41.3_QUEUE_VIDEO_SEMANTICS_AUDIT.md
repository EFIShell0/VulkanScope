# VulkanScope 0.41.3 Queue / Vulkan Video Semantics Audit

This release separates queue capability bits from extended Vulkan Video query availability.

- Queue capability booleans remain direct `VkQueueFlags` evidence.
- Zero `VkQueueFlags` is displayed as zero, not as a fabricated `VK_NONE` enumerant.
- `VkQueueFamilyVideoPropertiesKHR` availability is tracked independently per queue report row.
- A successfully queried zero video codec mask is `VK_VIDEO_CODEC_OPERATION_NONE_KHR`.
- Missing `VK_KHR_video_queue` becomes Not applicable; failed/missing query evidence becomes Unavailable or Unknown.
- UI, TXT, HTML and Database technicalReport carry the same query status and reason.
- No schema migration is required; schema 2 and technicalReport 3 remain unchanged.
- Corrected the known queue-bit mask from 0x577 to 0x57F so `VK_QUEUE_SPARSE_BINDING_BIT` is not also reported as unknown.
