## Demonstrated issue and repair scope
The supplied 1.0.11 real-device screenshots show the permissionless Turnip fallback dialog on an Android device where the normal SAF UI is not available to the user. The same no-SAF experience was requested for the remaining Analysis import paths, with toast feedback for fallback exports. The Turnip fallback dialog title also rendered with an unreadably dark default color. The supplied Android head artwork replaces the prior generic outline icon, and the update glyph loses its unwanted outer circular arrow.

Android documentation was rechecked for this release. The Storage Access Framework uses `ACTION_OPEN_DOCUMENT` / `ACTION_CREATE_DOCUMENT` to invoke the system document picker. PackageManager documentation states that implicit-intent resolution should use `MATCH_DEFAULT_ONLY` when resolution is intended to mirror `startActivity` behavior. 1.0.12 therefore centralizes picker preflight on a launch-equivalent default-handler check and uses the same check for Turnip, Analysis JSON import/export, raw technicalReport export and complete TXT/HTML export.

The Khronos Vulkan Registry was rechecked on 2026-09-08 and remains version 1.4.362 dated 2026-09-04. No Vulkan query/native/report/schema change is justified by this UI/storage routing release.
