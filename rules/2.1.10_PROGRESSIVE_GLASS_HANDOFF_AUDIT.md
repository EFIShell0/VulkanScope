# VulkanScope 2.1.10 Progressive Glass Handoff Audit

## Immutable predecessor
- VulkanScope 2.1.9 ZIP SHA-256: `a53b205776cce3848e61877720a80de60491d9fdcd74f8d8f68c0207a08cc1f4`.
- Extracted predecessor census: 756 files.
- The supplied 5.06-second runtime video shows the pager in normal flow and then a discontinuous jump to the top overlay while the list continues scrolling.

## Failure classification
- `REGRESSION/PAGINATION/HANDOFF`: 2.1.9 used a boolean pin threshold plus `AnimatedVisibility`, so the overlay began at the header lane rather than the pager's live pre-pin position.
- `USABILITY/GLASS/JOIN`: the pager-region glass appeared only after the boolean pin and therefore could not grow around the pager while it approached the header.
- `USABILITY/PERFORMANCE`: the requested system-style frosted surface requires blur-like diffusion without checker cells, framebuffer readback or repeated bitmap creation.

## Repair
- The lazy pager anchor is a normal `item`, not a sticky child.
- A bounded handoff progress is computed from live lazy-item offset, measured pager height, live header inset and 12 dp join padding.
- The overlay follows the live pager Y position and clamps only at the live header boundary; the normal and overlay pager crossfade at matching geometry.
- The top glass extension height is driven by the same progress, so it grows from the header edge to the pager lane and reverses continuously on upward return.
- Retained `GraphicsLayer` display lists feed one bounded API-31 blur render effect. The visible list uses the retained unblurred layer; the glass draws the retained blurred layer plus smooth tint gradients. No bitmap conversion, screenshot readback or checker texture is used.
- The transient-status lane target follows the moving pager bottom during partial handoff so status and scroll-hint surfaces remain ordered.

## Upstream API check
- Android Developers documents Compose `GraphicsLayer` as a retained display-list mechanism that can replay captured drawing instructions efficiently without re-executing application code.
- Android Developers documents blur render effects as supported on Android 12 / API 31 and newer. VulkanScope already requires API 31, so no older-platform fallback branch is introduced.
