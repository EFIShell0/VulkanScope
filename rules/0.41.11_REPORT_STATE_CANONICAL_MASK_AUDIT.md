# VulkanScope 0.41.11 reporting-state / canonical-mask audit

## Corrections

- Removed the generic zero-mask `NONE` presentation; generic zero masks now render as `0` while legitimate typed zero enumerants such as `VK_VIDEO_CODEC_OPERATION_NONE_KHR` remain typed and unchanged.
- Corrected `VkToolPurposeFlags` decoding to the registry bit assignments and canonical `VK_TOOL_PURPOSE_*` names, including debug-reporting/debug-marker bits and unknown-bit preservation.
- Preserved whole-format support independently from each queried linear/optimal/buffer feature mask so a zero buffer mask is not mislabeled as a supported buffer capability.
- Added explicit `UNKNOWN` profile-evaluation rows for cataloged profiles that the lightweight evaluator does not map, preventing current reports from silently omitting those known catalog entries.
- Retained exact Image Format Properties2 Available / Unsupported / Unavailable / Not applicable semantics.

## Packaging

The source-release policy excludes root README/release documents, packaged Fastlane/store metadata, caches, build outputs and transient dependency directories.
