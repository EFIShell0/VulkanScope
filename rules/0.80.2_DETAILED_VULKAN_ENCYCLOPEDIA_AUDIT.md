## User-visible correction
0.80.1's Overview Encyclopedia was too shallow: it documented evidence states and exposed three destination shortcuts, but it did not explain Vulkan symbols such as `VK_SUCCESS`, `vk*` commands or `Vk*` types in enough detail. 0.80.2 removes the Extensions, Profiles and Vulkan Video destination shortcut chips from the Encyclopedia and turns the card into a local searchable reference.

The default view explains VulkanScope evidence states, instance/physical-device/logical-device/queue/command-buffer concepts, features/properties/limits/formats, layers/extensions, Surface/WSI, swapchains, `pNext`, `sType`, loader/device/driver version separation and Vulkan naming conventions.

The `VkResult` category contains all 50 canonical published Vulkan 1.4.361 result values used by the current specification, with numeric values, concise meanings and compatibility aliases where applicable. Return-code meaning is explicitly scoped to the command outcome; it is not global capability evidence.

## Locked registry symbol index
`tools/generate_encyclopedia_symbols.py` deterministically derives a checked-in local index from `registry/upstream/vk.xml`. The current Vulkan-supported registry census contains:
- 842 registered `vk*` command names, including aliases;
- 6241 registered `VK_*` tokens/enumerants/macros after excluding disabled-only registry material;
- 2457 registered `Vk*` API types.

Search touches these larger indexes only after at least two input characters and visible results are capped at 24. The index is build/release-time generated; runtime registry download/parsing is not introduced. Registry/provider ownership is reference metadata only and never becomes runtime support evidence.

## Evidence semantics and design integrity
- Encyclopedia remains directly between `Capability snapshot` and `Analysis workspace`.
- It remains inside the established Material 3 Expressive capability-card language.
- It adds no nested vertical scroller; Overview's top-level `VulkanLazyPage` remains the only vertical scroll authority.
- `Supported`, `Unsupported`, `Unavailable`, `Not applicable` and `Unknown` remain distinct.
- Vulkan Video `Not applicable` explicitly describes only the Vulkan Video API path exposed by the selected driver and does not prove hardware video decode/encode absence.
- No destination navigation button remains inside the Encyclopedia.
- Overview does not eagerly instantiate the 474-entry extension reference table merely to display the locked registry census. The 474 count is release metadata; the extension reference collection is touched only when an extension search/category actually requires it.
