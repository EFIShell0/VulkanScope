## Demonstrated predecessor failures
The 0.80.2 Overview eagerly embeds the complete Encyclopedia and Analysis workspace. This makes Overview own Analysis-only state/calculations and renders Encyclopedia results inside one large section rather than as top-level lazy items.

The search crash has a concrete source cause. `generate_encyclopedia_symbols.py` first built field separators as `\\t`, then escaped backslashes again for Kotlin. The checked-in Kotlin source therefore stored literal backslash+t text. `decodeVulkanRegistrySymbol` searched for a real tab and then used delimiter indices without rejecting `-1`; a matched symbol row could throw `StringIndexOutOfBoundsException`.

Failing-before-fix: `tools/verify_overview_tools_search_0803.py --root <0.80.2>` expected FAIL and observed FAIL.

## 0.80.3 repair
- Overview keeps compact Material 3 Expressive Encyclopedia and Analysis workspace destination cards only.
- `Page.Encyclopedia` and `Page.Analysis` open separate pages and retain Overview as their parent navigation selection/back destination.
- Encyclopedia uses the common lazy page wrapper; individual result entries are lazy items.
- Analysis model/state is created only on the Analysis page.
- The symbol generator emits one Kotlin `\t` escape between fields, producing runtime tab delimiters.
- Decoder and search loops reject malformed rows before substring operations.
- Registry/VkResult reference semantics, result bound, no-network behavior and all Vulkan runtime evidence remain unchanged.
