# VulkanScope 1.5.4 landscape compact-navigation audit

## Scope
- Correct the remaining landscape overflow/misalignment of the compact floating bottom navigation bar.
- Match the compact landscape floating-tab footprint more closely to the Telegram reference supplied by the user while keeping VulkanScope styling, tab semantics and touch-target accessibility intact.
- Preserve 1.5.3 overlay-obstruction handling and all 1.5.3 Vulkan/report/security/runtime behavior.

## Requirements
- Landscape compact navigation must no longer expand to nearly the full app width. The width cap must be enforced in layout, not merely declared.
- Landscape compact navigation must use a tighter floating footprint than portrait: reduced host height, reduced selected-indicator height, slightly smaller icon size and tighter text spacing.
- The bar remains centered, rounded, floating above the Android navigation area and keeps tab semantics for all items.
- The existing dynamic top/bottom content clearance introduced in 1.5.3 remains active so page content and scroll indicators stay clear of both transient overlays and the floating navigation host.
- No build-chain, permission, network-policy, registry, native/JNI, report-schema or Database-behavior mutation may be introduced.

## Implemented design
- Replaced the compact-bar child `fillMaxWidth().widthIn(max = ...)` chain with a `BoxWithConstraints`-derived explicit `width(targetWidth)` measurement so the declared width cap is actually honored.
- Added a landscape compact profile: 340 dp max width, 46 dp host height, 35 dp selected-indicator height, 18 dp icon size, 8 sp labels and tighter internal padding/spacers.
- Kept portrait compact-navigation sizing unchanged.

## Expected evidence
- In landscape on narrow phones, the floating tab bar appears materially narrower and shorter, close to the supplied Telegram landscape footprint instead of spanning almost the entire width.
- Overview, Surface and other `VulkanLazyPage` destinations continue to scroll fully past the bar, with the last actionable rows remaining unobstructed.
- Android system navigation and VulkanScope compact navigation no longer compete for the same screen region.
