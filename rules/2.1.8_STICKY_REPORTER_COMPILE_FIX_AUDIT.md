## Observed regression oracle
The supplied Windows `:app:assembleRelease` build completed native CMake builds for arm64-v8a, armeabi-v7a and x86_64, then failed at `:app:compileReleaseKotlin`. Kotlin reported `MainActivity.kt:5056:52 Argument type mismatch: actual type is '(String, Boolean, Int) -> Any?', but '(String, Boolean, Int) -> Unit' was expected.`

The remembered `stickyPagerStateReporter` lambda ended with an `if` expression whose true branch performed indexed assignment while the false branch returned the result of `MutableMap.remove`. Because the conditional was the lambda's terminal expression, Kotlin inferred a nullable common result type instead of the required `Unit` callback type.

## Repair
The callback keeps the same keyed insert/remove side effects and adds an explicit terminal `Unit` expression. No sticky-pager state transition, overlay ordering, animation, file-manager behavior, trademark presentation, Vulkan query, report, Database or storage behavior is changed.
