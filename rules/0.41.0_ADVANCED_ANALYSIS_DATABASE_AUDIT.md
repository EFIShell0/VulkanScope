# VulkanScope 0.41.0 Advanced Analysis and Database Audit

Release target: VulkanScope 0.41.0 / versionCode 410.

The release preserves the Vulkan 1.4.360 collection/query baseline and schema 2 / technicalReport 3 while adding bounded registry-reference analysis, advanced local filtering, a diagnostic-evidence score, local QR/permalink sharing and matching Database trend/permalink support.

Dependency relationships are registry-reference metadata and are displayed separately from runtime extension enumeration and dedicated query evidence. Missing embedded metadata is not guessed. The authoritative Khronos extension page remains reachable for every extension token.

The diagnostic score uses only explicit collector errors and safety rejections and is not a conformance, benchmark, performance or hardware-quality result.

QR encoding occurs locally and adds no runtime network endpoint. Database URLs are fixed to the official HTTPS origin and report ids are validated as lowercase SHA-256 hex identifiers.

Database trends aggregate loaded submissions only. Extension absence is not interpreted as unsupported and trend percentages are explicitly not market share.

No canonical capability report field, report schema, Vulkan query path, update-security policy, Turnip path or native resource-ownership rule is changed by these analysis features.

- Visual graph rendering is locally bounded to 24 nodes while the cycle-safe registry-reference traversal remains bounded to 64 nodes / four levels and remains fully available as text.
Query-handler/reference parity is release-gated: every extension with a dedicated isolated query group is present in the known extension catalog and checked-in reference asset, and `handler:true` consults the application query map as well as reference metadata. Missing registry fields remain explicitly unavailable rather than inferred.

The visual graph uses real local node/edge rendering and is presentation-bounded to 24 nodes; the complete bounded textual traversal remains available at up to 64 unique nodes / four levels.
