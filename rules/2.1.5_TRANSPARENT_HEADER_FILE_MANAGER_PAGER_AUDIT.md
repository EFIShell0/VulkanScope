## Classification and patch boundary
- `USABILITY/HEADER`: make the app-bar backdrop substantially translucent and allow page content to occupy/scroll through the same viewport while preserving an initial header-safe content inset.
- `BUG/LANDSCAPE`: add left/right Android navigation-bar safe insets to header controls so side navigation cannot cover actions.
- `USABILITY/IDENTITY`: preserve all VulkanScope wordmark pixels while moving only the SCOPE glyph group vertically to align it with the Vulkan mark; keep the previous balanced asset immutable as predecessor evidence.
- `USABILITY/FILE-MANAGER`: generalize the six view modes to the shared-storage browser used by TXT/HTML/JSON and Analysis import/export; combine view and sort into one bounded expressive menu in both Turnip and shared-storage browsers.
- `USABILITY/SEARCH`: restore soft overflow fades only after measured text exceeds its viewport. Empty/short text receives no leading shadow; a leading fade is permitted only after actual overflow while editing.
- `USABILITY/PAGINATION`: remove the sticky pager's opaque full-width backing, use a translucent pager surface, and smoothly move a pinned pager below the top scroll-arrow region while rows continue behind it.
- `USABILITY/BACK`: reduce only the primary app-header Back circle while retaining its stable reserved slot.
- Production runtime changes are restricted to `MainActivity.kt` plus one derived local horizontal logo asset. `app/build.gradle.kts` changes release identity only. Native/JNI, Vulkan 1.4.364 registry/generated data, report/Database/export semantics, manifest, permissions, endpoints, ABI targets and dependency/build-chain pins remain predecessor-equivalent.
