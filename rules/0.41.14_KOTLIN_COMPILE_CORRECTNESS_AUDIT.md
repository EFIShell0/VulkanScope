# VulkanScope 0.41.14 Kotlin compile-correctness audit

## Trigger
A real `:app:assembleRelease` build of 0.41.13 completed native compilation for arm64-v8a, armeabi-v7a and x86_64, then failed in `:app:compileReleaseKotlin` because `imageFormatQueryGroupState` referenced a nonexistent `GpuInfo` type. The actual collected device model is `DeviceReport`. The unresolved receiver type then cascaded into unresolved `detailedProperties`, lambda `it`, and `value` references.

## Correction
The helper now accepts `DeviceReport`. No query-state logic or report payload semantics were changed.

## Regression gate
The release verifier requires the exact `DeviceReport` helper signature and rejects the stale `GpuInfo` signature.
