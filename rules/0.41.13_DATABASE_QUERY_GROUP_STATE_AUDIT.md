# VulkanScope 0.41.13 Database query-group state audit

## Trigger
VulkanScope 0.41.12 could produce a rules-valid complete report in which the isolated Image Format Properties2 group ended explicitly Unavailable, while Database 0.39.10 still required tuple-level ledger evidence and returned HTTP 400.

## Producer correction
- The completed report now clears `imageFormatQueryResults` whenever the `imageFormat2` group is not Available, preventing stale tuple evidence from surviving a failed/non-applicable collection cycle.
- Schema-3 technicalReport device objects additionally expose `imageFormatQueryStatus` and `imageFormatQueryReason`, derived from the existing Vulkan Query Status row.
- Available query groups keep the exact complete tuple ledger and successful property payload behavior unchanged.
- Unavailable/Not applicable groups remain explicit evidence; no tuple rows are fabricated.

## Consumer contract
VulkanScope Database 0.39.11 accepts explicit 0.41.12 query-group Unavailable/Not applicable evidence and validates 0.41.13's structured state against the existing query-status row. Available groups retain all complete-ledger cross-checks.
