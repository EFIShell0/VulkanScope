# VulkanScope 3.0.3 Analysis, File Manager and TV Audit

## Scope

VulkanScope 3.0.3 is a presentation, local-workflow and input-navigation release based on the immutable VulkanScope 3.0.2 source ZIP (`89ea5989b77dacc7a54f17978d687068140d5d62829edc466799337290517430`, 806 files). Production changes are limited to `MainActivity.kt`, `VulkanDependencyGraph.kt` and release identity. The manifest, native/JNI collector, checked-in Vulkan registry/generated data, report/Database/export schema and endpoint behavior, permissions, ABI targets and dependency versions remain byte-equivalent to 3.0.2.

## Custom minimum actions

Saved minimum profiles now expose contained VulkanScope-red Load and Delete actions. Load uses the existing update-action icon and Delete uses the trash icon. Save, Load and Delete first create a local pending-confirmation state and do not call the corresponding mutation until the question-style dialog confirm action is pressed. Cancel or dialog dismissal clears only the pending confirmation. The Save, Load and Delete dialogs share `QuestionDialogTitle`, the raised bordered dialog surface and the common Cancel control used by established confirmation flows.

## Dependency graph presentation

The graph remains a bounded view of checked-in registry relationships. The redesigned visual map separates depth lanes, edge relationships and runtime evidence state. Present, Not exposed, Unknown and Not applicable are presentation states derived from the existing evidence strings; they are not new Vulkan queries or inferred conformance claims. The visual surface is scrollable on both axes and capped at 24 nodes while the complete bounded traversal list remains visible below it.

## Turnip file manager

The Turnip package browser now occupies the full application content area rather than a floating dialog. It protects live status/navigation insets and leaves the Android navigation inset to the retained VulkanScope navigation backdrop, preserving the existing blurred system-navigation treatment. The path is represented as root-relative clickable breadcrumbs separated by `>`. Existing canonical-root validation remains authoritative.

Folder secondary text is no longer the generic `Folder` label. Each visible folder receives a bounded one-level scan of readable `.zip` entries, capped at 256 before the UI reports a `+` suffix. The count does not recurse and does not validate or import archives. Search is collapsed into a round icon action and expands/closes with bounded animation. The shared view/sort chooser ignores dismissal requests and closes only through its X control.

## Android TV navigation

TV lazy pages intercept D-pad Up/Down at the preview phase. VulkanScope first requests focus movement. When the next target is not in the composed lazy viewport, the owning lazy state performs a bounded animated scroll, waits one short frame interval and retries focus movement. Page Up/Page Down provide viewport jumps. Turnip/shared-storage lazy lists and grids use the same bounded fallback. Folder/file cards are directly actionable, and redundant chevron focus is disabled on TV where the parent card owns the same action.

## Report-ID copy feedback

The successful Database report-ID copy action uses a transient icon state machine: idle copy icon → busy → green check on clipboard success or red close on failure → idle after 3000 ms. The state is local UI feedback only and does not submit, refetch or modify a report.

## Verification boundary

The targeted verifier checks release identity, UI/state-machine anchors, graph presentation constraints, protected-file hashes and the no-source-comment rule. The regression verifier compares the 3.0.3 tree to an extracted 3.0.2 predecessor and allows production byte drift only in `MainActivity.kt`, `VulkanDependencyGraph.kt` and release identity. Static gates do not substitute for Android compilation or runtime replay.

Android Gradle compilation was attempted in the working environment but the required Gradle 9.7.1 distribution was not locally available and network access to `services.gradle.org` failed. Therefore Android compilation is not recorded as PASS for this release artifact.
