## Demonstrated predecessor gaps
Static inspection of 0.80.5 found redundant accessibility descriptions on scroll-boundary arrows, navigation icons and vendor artwork; dynamic collection/update status surfaces had no live-region semantics; section/release-note headings lacked heading semantics; Direct GitHub updates and driver radio rows could expose both a parent row and nested control as separate actions.

The same audit found large-text/display-size pressure points: Quick Access forced four columns with fixed 72dp cards, the compact navigation rail forced 54dp item heights, several status rows forced one-line text, and key/value/update metadata remained side-by-side regardless of large font scale or narrow effective width.

The 0.80.6 verifier is run against immutable 0.80.5 with version checking disabled and fails for these demonstrated gaps rather than only for version metadata.

## Current Android basis
Official Android accessibility guidance was rechecked on 2026-09-05. Compose semantics are the accessibility contract used by TalkBack. Android 14+ supports nonlinear font scaling up to 200% and explicitly recommends testing the maximum font size even when text uses sp. Current Android guidance also requires adaptive layouts to reflow rather than overlap or hide content as display size and text scale change.

## 0.80.6 correction
- Decorative/redundant icon descriptions are removed where visible text or the parent control already carries the meaning.
- Collection status becomes one polite live-region announcement; update status gains polite live-region semantics.
- Capability section and release-note headings expose heading semantics; key/value rows merge key + value for coherent TalkBack traversal.
- Direct GitHub updates use one parent Switch semantic target with a presentation-only nested Switch. Driver choices use one parent RadioButton semantic target with presentation-only nested radio controls.
- A large-text/narrow-layout branch activates at fontScale >= 1.3 or screenWidthDp < 360 without manual font-size conversion.
- Overview metric pairs stack, Quick Access reduces from four to two columns, Quick Access cards use minimum rather than fixed height, key/value/update metadata stacks, Info metadata pills and paired export actions stack, and the compact rail widens while rail items use natural growable content height and can grow to two lines.
- The app header uses one scalable textual destination title in the expanded-text layout instead of competing fixed logo/title geometry.
- Collection status text can wrap instead of being forcibly ellipsized to one line.
- The update release-notes viewport remains 360dp normally and reduces to a bounded 220dp under expanded text, retaining existing scrolling, TV focus and boundary indicators.

## Evidence boundary
Source/state-machine tests do not prove real TalkBack traversal or visual correctness at every OEM density/font combination. TalkBack hardware/emulator traversal, Accessibility Scanner/instrumented semantics, 200% font-size screenshots, enlarged display-size testing and portrait/landscape runtime testing are separate evidence classes and remain NOT EXECUTED unless explicitly run.
