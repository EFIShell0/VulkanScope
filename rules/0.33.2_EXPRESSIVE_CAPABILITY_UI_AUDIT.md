# VulkanScope 0.33.2 Expressive Capability UI Audit

- Baseline: VulkanScope 0.33.1.
- Scope: Overview, Vulkan, Display & HDR, Surface, Features, Memory, Queues, Formats, Properties & Limits, Extensions, Profiles.
- Info and Settings remain the visual reference and are not structurally redesigned.
- Capability section cards use expressive dark surfaces, rounded geometry, rose accent icon containers, and consistent section hierarchy.
- Capability key/value rows wrap long values instead of dropping information.
- Dense feature/format/property/extension/profile records use expressive item containers while preserving every field and status.
- Overview hero, metrics, quick access, and Explore are aligned to the same visual system.
- No Vulkan query, report schema, collection, Turnip/SAF, update, export, or Database logic was intentionally changed.
- Capability-state semantics remain unchanged.
