## User-observed regression oracle
- The supplied app screenshot shows the 2.1.6 square-tile pattern as visually coarse. The supplied reference top bar is instead a smooth, dense translucent glass surface with no visible checker/tile cells.
- The shared file-manager popup still uses the same generic sort glyph for multiple sort rows, so the six sort meanings are not visually distinguishable at a glance.
- The supplied paged-list behavior shows the page card can still lose its intended coordinated position after scrolling, and the requested overlay order is app header, pinned page card, transient status surfaces, then the top scroll indicator.
- Numeric page editing remains active when previous/next is pressed. Arrow navigation must discard that pending edit, clear focus and show the destination page number.
- User-facing self-test text spells SPIR-V without its Khronos trademark mark.

## Classification and patch boundary
- `USABILITY/HEADER`: remove the deterministic block-cell pattern and use a bounded smooth translucent backing with a subtle continuous vertical light/dark treatment. No framebuffer capture, background bitmap allocation or unbounded blur pipeline is introduced.
- `USABILITY/FILE-MANAGER`: retain six existing layouts, but give all six sort modes distinct semantic vector icons. The combined options trigger keeps the active layout glyph and its sort badge now reflects the active sort mode.
- `BUG/PAGINATION`: a pinned pager reports its measured height to the shared overlay coordinator. Multiple sticky pagers are tracked by key so one unpin cannot erase the inset required by another still-pinned pager.
- `USABILITY/OVERLAY`: pinned page controls join directly below the app header. Transient status surfaces move below the pinned pager, and the top scroll indicator moves below both. Only the pager region receives the matching glass backing while pinned; that backing and vertical offset animate only for pin/unpin transitions.
- `USABILITY/PAGINATION`: previous/next actions in collection and filter pagers replace any in-progress numeric edit with the target page, clear focus and retain a bounded page-number cross-fade. Whole pager surfaces do not animate when only the page number changes.
- `USABILITY/TRADEMARK`: user-facing Vulkan self-test presentation uses `SPIR-V™`, matching the Khronos trademark list. Canonical registry text, generated registry data and native self-test JSON remain unchanged.
- Production changes are restricted to `app/src/main/java/com/efishell/vulkanscope/MainActivity.kt` plus six new local vector drawables for sort semantics; `app/build.gradle.kts` changes release identity only. Native/JNI, Vulkan 1.4.364 registry/generated data, report/Database/export semantics, manifest, permissions, endpoints, ABI targets, dependency pins and packaged identity artwork remain predecessor-equivalent.
