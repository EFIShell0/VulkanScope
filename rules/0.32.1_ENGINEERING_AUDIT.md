# VulkanScope 0.32.1 engineering / visual-scope audit

0.32.1 is rebuilt from the 0.31.1 package and reapplies the 0.32.0 engineering fixes. The UI delta is intentionally limited to InfoPage, SettingsPage, DriverOption and new Info/Settings-only expressive helper composables. Shared SectionCard/DataRow/MetricCard/navigation rendering is unchanged from the original visual baseline.

Preserved engineering changes: API 37, NDK r29, Vulkan-Headers 1.4.360 immutable commit, validated query baseline distinction, structured technicalReport Database payload, 2 MiB no-truncation transport gate, Turnip meta.json canonical-path validation, export parity, semantic HTML status colors, native RELRO/now flags and Gradle wrapper scripts.

Static verification is provided by tools/verify_release.py plus XML/JSON/Python checks. A full APK/NDK build is not claimed unless Gradle dependencies and Android SDK/NDK are available in the execution environment.
