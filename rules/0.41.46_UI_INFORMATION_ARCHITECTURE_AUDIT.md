## Demonstrated gaps
- USABILITY: Vulkan Video exact-profile evidence exists in the canonical report but is buried inside Properties & Limits rather than having a dedicated codec/profile-oriented view.
- USABILITY: Analysis is exposed as a separate destination/button even though the requested information architecture places those local tools directly below Capability snapshot on Overview.
- USABILITY: scrollable pages provide no persistent visual evidence of whether additional content exists above or below the current viewport.
- USABILITY: Info does not enumerate the release-pinned direct application/native library identities and versions used to build VulkanScope.
- TEST-GAP: there is no release gate proving boundary arrows disappear independently at the top and bottom, no gate preventing Analysis from returning as a destination, and no gate binding the Info library presentation to the actual pinned dependency versions.

## Upstream/UI evidence
- Android `LazyListState.canScrollBackward` is false at the minimum scroll position and `canScrollForward` is false at the end; Android's official API example uses those exact properties to hide up/down arrow indicators.
- `LazyColumn` remains the appropriate lazy container for long capability lists. The release must preserve lazy rendering rather than replacing large lists with eager nested Columns.
- Vulkan Video UI rows remain presentation over existing 0.41.45 `Vulkan Video` detailed-property and queue evidence. No capability inference, query expansion or report-schema change is introduced.
