# VulkanScope 0.33.10 Properties & Limits Summary Audit

The 0.33.9 UI summary mixed detailed property-query rows with limit rows under labels that implied they were the same data class. This was presentation-only but made a stable producer property count appear to increase.

0.33.10 separates the counters. All shows property query results, unique property names, and limits independently. Limits shows only limits. Unique property names is derived exclusively from detailed property rows. Search filtering is applied independently before each count is computed.

No native Vulkan query, report payload, TXT/HTML export field or Database submission field is changed by this release.
