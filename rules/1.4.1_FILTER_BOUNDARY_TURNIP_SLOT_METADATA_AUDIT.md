# VulkanScope 1.4.1 filter boundary and Turnip slot metadata audit

## Scope
This release addresses two user-directed UI defects only: filter-result scroll chaining into the parent page at list boundaries, and missing Turnip package description/library metadata on the managed slot cards.

## Filter boundary root cause
`LazyColumn` correctly consumes motion while it can move. At its first/last item, Compose exposes the remaining vertical delta/velocity to the nested-scroll parent. Because the in-layout filter lives inside a scrollable page, that remainder moved the page once the filter options were exhausted.

The 1.4.1 fix installs a shared `NestedScrollConnection` around each active filter result-list host. It consumes only **post-scroll** residual Y delta and **post-fling** residual Y velocity. It does not implement `onPreScroll`/`onPreFling`, so the filter list receives normal motion first and remains independently scrollable. The connection is scoped to the result list, so ordinary page scrolling elsewhere remains unchanged.

## Turnip slot metadata
`TurnipBundleInfo` already retains validated `libraryName` and parsed `description` metadata from the established Turnip package path. The Details dialog already exposed those fields. 1.4.1 reuses exactly those values in the managed slot cards:
- `Vulkan® library` -> `info.libraryName`, fallback `Not available`.
- `Description` -> nonblank `info.description`, fallback `Not provided`.

No archive-validation, extraction, source-provenance, activation, removal, report, Database or metadata-schema behavior changes.

## Responsive presentation
Wide slot cards keep their existing identity/source/state/action row and place the two new metadata pills beneath a divider. Compact and expanded-text layouts use full-width metadata pills before the existing driver/package pills so long library/description values do not squeeze the driver/state header.

## Verification
Targeted verifier/state-machine/negative-mutation/regression gates must prove both single- and multi-filter containment, scroll/fling residual consumption, both responsive Turnip metadata presentations, immutable production scope outside `MainActivity.kt`, and release-identity-only `build.gradle.kts` drift.
