# VulkanScope 0.32.5 update confirmation and export gate audit

- Base: VulkanScope 0.32.4.
- New-version discovery remains asynchronous and HTTPS-only through the official EFIShell0/VulkanScope GitHub Releases API.
- Startup discovery remains non-modal. Manual Settings discovery opens the same update confirmation dialog as the update-available banner.
- No APK bytes are downloaded until the user confirms Download APK.
- The dialog shows installed version/versionCode, installed ABI, selected download ABI, selected asset, available release version and official GitHub release notes.
- Release-note lines are rendered through a bounded-height LazyColumn as inert Compose text.
- Existing downloaded-APK provenance, package, signing-certificate and monotonic version validation remains unchanged.
- TXT and HTML export buttons share the complete-report collection gate with Database submission and remain disabled while collection is active.
- Settings exposes the public Database URL while the submission API endpoint remains fixed and non-editable.
- Vulkan 1.4.360 query coverage, canonical flag handling and structured Database payload behavior are unchanged from 0.32.4.
