# VulkanScope 0.34.4 IzzyOnDroid first-run update notice

- Direct GitHub updates remain opt-in and disabled by default.
- On a genuine first installation, when direct updates remain disabled, VulkanScope shows one non-modal information banner for seven seconds.
- The banner uses the existing update-status banner component and visual language.
- The message states that direct GitHub updates are disabled by default and can optionally be enabled in Settings.
- The notice is stored as seen before display and is never repeated on later launches.
- Existing users upgrading from an older version do not receive a false first-install notice; Android first-install and last-update timestamps must match before display.
- Enabling direct updates still requires the separate IzzyOnDroid bypass confirmation.
- No network request is made by the notice.
- Vulkan 1.4.360 capability collection, reporting and Database behavior remain unchanged.
