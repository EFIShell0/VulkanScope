# VulkanScope 2.1.3 Telegram Header, Paging, Sort and Dialog Audit

## Scope

VulkanScope 2.1.3 is a UI/workflow refinement over immutable 2.1.2. Production deltas are restricted to `MainActivity.kt`, release identity, one local sort icon and one balanced horizontal logo asset. Native/JNI collection, the Vulkan 1.4.364 registry lock, report/Database/export semantics, manifest, permissions, endpoints, ABI targets and dependency/build pins are outside the change surface.

## Header and text-edge behavior

The app header no longer uses the rounded floating outer card required by 2.1.2. Its translucent backdrop spans the full width/status region while action/logo/title content respects system insets. Back is a 42 dp circle in a stable 50 dp slot; Settings remains 50 dp. Both use the existing Vulkan red action family and bounded slide/fade/scale transitions. The packaged balanced horizontal logo removes asymmetric transparent outer padding.

Search edge masking is conditional on measured overflow. Active editing has no overlay over the leading text or caret; an unfocused overflowing value may fade only at the trailing text edge, inside the field and away from its border.

## Paging

`COLLECTION_PAGE_SIZE` is 25. Shared pagers reject nonexistent page numbers, defer commits until IME Done/focus loss, live directly above result rows and become sticky while result content scrolls. Directional pager motion is bounded. Paging is applied only to visible presentation lists and never changes source evidence or exported/submitted data.

Coverage includes Features, Formats, Properties & Limits, Extensions, Surface format/color-space results, Profiles, Encyclopedia, queue-family lists, Vulkan Video matrix/decode/encode/format/queue lists and list-heavy Analysis workspace result families, including saved custom profiles and custom minimum evaluations.

## File browsers

Turnip and shared-storage scanners sort the already bounded/canonical child list using one of six local modes: A–Z, Z–A, modified newest/oldest and created newest/oldest. Creation time uses `BasicFileAttributes.creationTime` with bounded last-modified fallback. Shared-storage sort applies to the browser reused by TXT/HTML/JSON and analysis import/export flows. Existing canonical-path, symlink, size and entry bounds remain intact.

## Dialog and safe-area treatment

Material AlertDialogs plus custom detail/license/Turnip/shared-storage dialog containers use the selected-Turnip red outline family. Main-page intersection fade masks are removed. File-browser edge fades remain scoped to their bounded browser content. Compact bottom navigation consumes Android left/right/bottom navigation-bar insets, including landscape side navigation.

## Evidence

Targeted static verification checks release identity, predecessor invariants, paging coverage and input bounds, header/search structure, balanced-logo use, file sort coverage, dialog borders and landscape insets. State-machine tests cover page input and sort ordering. Negative mutation tests prove each required signature is enforced while an unrelated audit-text mutation remains accepted. Android assemble/runtime/device screenshot evidence remains separate and is not represented as PASS unless executed.
