## Demonstrated issues and requested repair
The supplied 1.0.6 runtime feedback identifies information-architecture and presentation defects rather than Vulkan evidence defects: the separate Turnip source selector is redundant with managed-slot activation; connectivity feedback disappears while collection is active; the filter continuation remains visibly abrupt and arrow availability changes without motion; Turnip slot state does not communicate recorded Source ZIP reachability; Remove and Close actions lack the requested iconography; and Extension explorer should reuse the shared information glyph.

## Production repair
Settings now retains the System Vulkan driver selector as the only driver-source selector and renders Turnip driver manager as a separate persistent section. Unsupported or unknown Turnip eligibility exposes only an amber Unavailable explanation. Managed slots preserve private validated packages while separately testing whether the recorded source URI/path is still readable. Active, Available and Unavailable remain distinct visual states, and SAF imports best-effort retain read permission without making grant persistence a prerequisite for an already validated private package.

Connectivity and collection states coexist. Network transitions are not paused or hidden during collection, the persistent offline information surface may appear while collection continues, and Database submission distinguishes collection-only, network-only and combined locks. The network state path remains callback-driven and does not introduce probe traffic.

The shared filter carousel replaces black edge drawing with surface-colored continuation masks, reserves edge-control space in the lazy content and animates arrow/mask state changes. Shared detail dialogs gain an info header glyph and contained X Close action. Turnip Remove gains a trash glyph while Details remains the shared Extensions affordance. Extension explorer uses the same information glyph as the offline information surface through the Vulkan accent treatment.
