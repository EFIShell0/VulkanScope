# VulkanScope 0.33.8 Build Fix Audit

## Reported failure

The supplied `:app:assembleRelease` log reached native builds for arm64-v8a, armeabi-v7a and x86_64, then failed in `:app:compileReleaseKotlin` because `MainActivity.kt` referenced `TextAlign.End` without importing `androidx.compose.ui.text.style.TextAlign`.

## Correction

- Added the missing Compose `TextAlign` import.
- Bumped the application to 0.33.8 / versionCode 338.
- Added a release-verifier gate for the required import.
- Preserved the 0.33.7 Vulkan/report/Database/display/update/Turnip behavior.

## Native warnings

The reported libadrenotools messages are compiler warnings from the pinned third-party dependency and did not stop the build. The actual build-stopping diagnostic was the unresolved Kotlin `TextAlign` symbol.
