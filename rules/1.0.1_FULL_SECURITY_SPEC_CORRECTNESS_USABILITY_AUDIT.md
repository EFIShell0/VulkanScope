## Demonstrated 1.0.0 defects
- `CRASH/BUG`: bounded Analysis history write/rename and directory operations were not enclosed by an outer fail-closed I/O boundary, so a storage exception could escape the collection-side coroutine.
- `CORRECTNESS`: custom minimum limit rules converted exact Vulkan numeric evidence to `Double`, which can miscompare 64-bit values above 2^53.
- `CORRECTNESS`: invalid feature expectation tokens were implicitly treated as false, and ambiguous feature/limit suffix matches selected the first match instead of remaining Unknown.
- `CORRECTNESS`: dependency graph core-version evidence turned missing/unparsable API evidence into a false negative; extension absence text did not respect incomplete/unavailable enumeration authority.
- `PERFORMANCE`: entering Analysis eagerly built and flattened the complete technicalReport even on tabs that did not use raw structured JSON.
- `BUG/PERFORMANCE`: the selected-evidence watch action could invoke both an explicit and ambient watcher callback for one user action.
- `CORRECTNESS/USABILITY`: Diagnostics text claimed that per-query durations were never published even though dedicated/on-demand probe elapsed timings can be measured and displayed.
- `USABILITY`: the shared filter bar used a horizontal scrolling strip, making a 15-destination Analysis workspace and long translated filter labels less discoverable on narrow/large-text layouts.

## Corrections
History persistence/load/delete now fail closed around private-storage I/O. Minimum numeric evaluation uses exact decimal comparison; feature tokens and ambiguous names are validated explicitly. Dependency evidence preserves Unknown/Incomplete/Unavailable/Not applicable semantics. Structured technicalReport leaf materialization is restricted to Raw JSON/Database tabs and explicit export. Watched evidence resolves one writer. Diagnostics wording matches actual timing evidence. Shared filters wrap with Compose `FlowRow` rather than hiding destinations in a horizontal strip.

## Non-regression boundary
