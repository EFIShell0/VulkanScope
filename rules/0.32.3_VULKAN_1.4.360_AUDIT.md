# VulkanScope 0.32.3 Vulkan 1.4.360 audit

Validated registry delta from Vulkan 1.4.357 through 1.4.360. Vulkan 1.4.358 adds VK_EXT_image_tiling_control with VkPhysicalDeviceImageTilingControlFeaturesEXT. Vulkan 1.4.359 adds VK_EXT_cooperative_matrix_maintenance1 with VkPhysicalDeviceCooperativeMatrixMaintenance1FeaturesEXT and vkGetPhysicalDeviceCooperativeMatrixProperties2EXT. Vulkan 1.4.360 adds no new extension.

Both new device extensions are automatically scheduled only when enumerated at runtime. The cooperative-matrix maintenance query first reads its feature structure; the properties2 command is called only when cooperativeMatrixProperties2 is supported and the command pointer is exposed. The baseline query uses subgroup scope, subgroupSize 0, invocations 0 and flags 0, which is a defined query form. Query results are bounded to 4096 returned records.

Application-side canonical flag display now uses official VK_* identifiers for memory, queue, video codec and VkFormatFeatureFlags2 values. Structured Database schema 4 preserves exact unsigned decimal strings for 64-bit masks while retaining legacy numeric fields for compatibility.

## Canonical flag audit
- `VkMemoryHeapFlags`: `VK_MEMORY_HEAP_TILE_MEMORY_BIT_QCOM` is `0x00000008` in the pinned 1.4.360 header.
- Surface `VkSurfaceTransformFlagsKHR`, `VkCompositeAlphaFlagsKHR`, and `VkImageUsageFlags` are emitted with canonical `VK_*` names plus their raw values.
- The Database technical report remains schema version 3; exact unsigned-decimal and canonical-name fields are additive to preserve deployed Database compatibility.
