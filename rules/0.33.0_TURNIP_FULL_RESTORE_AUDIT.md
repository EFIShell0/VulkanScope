# VulkanScope 0.33.0 Turnip/SAF full restoration audit

VulkanScope 0.33.0 restores the entire Turnip/SAF behavior from 0.32.4 rather than restoring only the Storage Access Framework launcher.

Restored from 0.32.4:
- `driverPickerLauncher`
- `openDriverBundlePicker()`
- `installDriverBundle()`
- `findTurnipBundle()`
- `findTurnipIcd()`
- `isTurnipPlatformEligible()`
- `updateTurnipSupport()`
- `requestDriverModeChange()`
- `findInstalledTurnipLibrary()`
- Turnip/System driver Settings enablement and Turnip ZIP import action

Native Turnip integration files were already unchanged from 0.32.4 and remain identical:
- `app/src/main/cpp/CMakeLists.txt`
- `app/src/main/cpp/vulkanscope.cpp`
- `app/src/main/java/com/efishell/vulkanscope/VulkanProbeService.kt`

Unrelated later improvements remain in place, including Vulkan 1.4.360 query coverage, HDR presentation, update confirmation, exact structured report data, TXT/HTML completeness gating, and Database submission compatibility.
