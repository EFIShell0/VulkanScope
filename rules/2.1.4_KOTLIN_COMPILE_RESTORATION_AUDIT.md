# VulkanScope 2.1.4 Kotlin Compile Restoration Audit

## Scope

VulkanScope 2.1.4 is a compile-regression repair over immutable VulkanScope 2.1.3. The predecessor ZIP SHA-256 is `7eb9f629f3a45287eebf76d1b028fddb2c667533f3efdbfee401adf277699550` with 720 files. Runtime production changes are limited to `MainActivity.kt`; `app/build.gradle.kts` changes release identity only. Native/JNI, Vulkan 1.4.364 registry data, manifest, report/Database/export semantics, permissions, endpoints, ABI targets, dependencies and UI behavior requested by 2.1.3 remain unchanged.

## Observed regression

The supplied release build reached `:app:compileReleaseKotlin` after all three native ABI builds. Kotlin then failed first on the invalid top-level `androidx.compose.foundation.lazy.stickyHeader` import and then on missing Vulkan Video helper declarations, including `VideoProfileEvidence`, `parseVulkanVideoEvidence`, `videoEvidenceState` and `videoPropertyLabel`. The same missing block also caused the subsequent unresolved profile/property/status symbols.

## Repair

`stickyHeader` is used as the `LazyListScope` member API and therefore has no top-level import. The Vulkan Video evidence model/parser/state/label helpers are restored byte-for-byte from the immutable 2.1.2 implementation because 2.1.3 pagination was presentation-only and had no authority to delete them. Queue-family `Video codec query` and retained `Video codec operations` rows are restored because their accidental deletion was a display regression unrelated to pagination.

## Evidence

`tools/verify_release_2104.py` rejects the invalid stickyHeader import, missing VideoProfileEvidence/VulkanVideoEvidence/parser/state/label helpers, dropped queue video evidence, stale version identity and any regression of the 2.1.3 UI/workflow contract. `tools/test_release_2104_negative_mutations.py` reintroduces each compile/display defect and requires verifier failure while a documentation-only mutation remains accepted. Android compilation remains a separate evidence class and is not claimed PASS unless an actual Gradle/Kotlin build completes.
