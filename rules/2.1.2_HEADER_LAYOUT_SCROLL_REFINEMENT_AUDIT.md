# VulkanScope 2.1.2 header, layout chooser and scroll-refinement audit

## Scope
- Release identity: VulkanScope 2.1.2, versionCode 2102.
- Immutable base: VulkanScope 2.1.1. Vulkan 1.4.364 registry/query locks, native/JNI collectors, report/database/export semantics, permissions, endpoints, ABI targets and build-chain pins remain predecessor-equivalent.
- 2.1.2 is a UI-only refinement driven by the supplied device screenshots and the supplied ZArchiver layout-selector reference.

## Header and action geometry
- The floating VulkanScope header begins below the Android status bar/camera-cutout region. The status bar is not painted inside the rounded header surface.
- Left and right action slots are equal and reserved so the central logo/title composition remains symmetrical while Back or Settings animates out.
- Back and Settings share the same 50 dp red rounded action surface, border, icon scale and shadow. Back enters/exits from the start edge; Settings uses the matching end-edge motion.
- The legacy `HOME` / `CURRENT SECTION` stack is removed. The section name is presented as a compact accent pill beside the VulkanScope logo.

## Paging behavior
- Collection page entry is edit-first, commit-later. Numeric keystrokes update only the local text field and must not call `onPageChange`.
- Page navigation commits on IME Done or true focus loss after clamping the entered value to the available page range.
- The 50-item presentation limit remains unchanged and cannot truncate collection/report/export/Database/profile data.

## File-manager layout chooser
- The single current-layout icon remains the only persistent layout button.
- Its popup is a ZArchiver-inspired compact 3×2 icon grid for all six layouts with an accent underline on the selected mode.
- Dense grid uses a 92 dp adaptive minimum cell width versus 156 dp for regular grid and reduced internal padding/icon sizing, so both modes are visibly different.
- Large tiles use horizontal icon/text/action alignment rather than the former vertically drifting layout.

## Back navigation and edge treatment
- Turnip File Manager and shared-storage browser use the same animated red Back action. At `/storage/emulated/0` the Back control animates out while its reserved slot prevents title jumping; entering a child folder animates it back in.
- Search-field text clipping uses narrow horizontal container-color gradients constrained to the text line, avoiding abrupt glyph clipping without painting over the field border.
- Main pages, Turnip File Manager grids/lists and shared-storage file/folder lists use animated top/bottom soft fade intersection treatment. Dialog lists blend the fade with the raised dialog surface.

## Evidence
- `tools/verify_release_2102.py` checks release identity, header/status-bar separation, symmetric red actions, deferred page commit, 3×2 chooser, distinct 92/156/228 dp grid tiers, large-tile alignment, search fades, file-manager list fades and immutable correctness files.
- `tools/test_release_2102_state_machine.py` models deferred page commit, root/subfolder Back visibility and layout-size ordering.
- `tools/test_release_2102_negative_mutations.py` must reject representative regressions and accept an unrelated documentation-only mutation.
- Android assemble/runtime/device visual comparison remain separate evidence classes and are not claimed unless actually executed.
