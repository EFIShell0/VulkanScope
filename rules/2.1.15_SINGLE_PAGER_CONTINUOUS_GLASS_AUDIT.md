# VulkanScope 2.1.15 Single Pager / Continuous Shared Glass Audit

## Immutable predecessor and runtime oracle
- Immutable predecessor: VulkanScope 2.1.14, 781 files, ZIP SHA-256 `02037944d32d02377c0a45fe03020d915a8b0e34080ccb99b7e34b4e872e08ee`.
- Supplied runtime oracle: `WhatsApp Video 2026-09-27 at 19.52.19.mp4`, duration 5.482 seconds.
- The observed defect is presentation state: reverse scrolling does not make the pager settle into the reserved list position as one continuous object, and the pager glass is visually disconnected from the app-header blur/tone.
- Post-fix device replay is not available in this packaging environment and is not claimed PASS.

## Research boundary
- Android's `LazyListItemInfo.offset` is the main-axis item offset in pixels relative to the start of the lazy-list container; this is the authoritative live anchor coordinate while the pager spacer is visible.
- Compose `GraphicsLayer` retains drawing instructions and can replay them efficiently; `RenderEffect` rasterizes the affected layer offscreen. The implementation therefore keeps one bounded retained source/blur pair for the lazy page and does not capture framebuffers or allocate screenshots.

## Root cause
- 2.1.14 changed ownership at the join threshold: the lazy item rendered a real pager outside the join region while the page overlay rendered another pager inside the join/pinned region. Even with mutually exclusive visibility, the transfer depended on lazy composition timing and made reverse landing visually discontinuous.
- 2.1.14 also blurred the pager join from a page-local layer while the app header/navigation sampled a separate root chrome layer. Matching radius/tint values did not guarantee a continuous backdrop because the sampled source differed.

## Repair
- The lazy item is now permanently a same-height spacer. One page-level pager renders for every visible/bridgeable/pinned state and follows the spacer's exact live offset until the header boundary clamps it. No whole-pager position tween or composable ownership swap remains.
- Pager height stays retained by the page owner and is updated by the single overlay pager measurement, so the spacer and visual pager share the same height after bootstrap.
- Each active Vulkan lazy page reports its retained blurred layer and root offset to the shared chrome host. Header and compact bottom navigation sample that same layer while it is active. The join extension already uses that layer directly, so all three surfaces share the same blur source, radius and tint.
- Join glass height is scroll-derived from the same progress that moves the pager toward the header. It is full width, starts at the live header boundary, carries no separator border and has no independent animation.

## Performance, security and semantic review
- No Vulkan/native/JNI, report, Database, Turnip, network, permission, endpoint, ABI, registry or dependency behavior changes.
- No PixelCopy, framebuffer readback, bitmap screenshot or per-frame bitmap allocation is introduced.
- The lazy list remains lazy; the pager is one composable plus one reserved spacer.
- System navigation insets and root offsets remain live layout values for portrait and landscape.
