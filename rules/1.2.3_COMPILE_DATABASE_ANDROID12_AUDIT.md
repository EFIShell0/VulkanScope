# VulkanScope 1.2.3 compile, Database result and Android 12 minimum audit

## Immutable predecessor
VulkanScope 1.2.2 is immutable predecessor evidence. Its ZIP SHA-256 is `f7ee0e0ad5c756f04e081d96928cc4009df9ac15a6526849a4bf020ddd9abd6d` and its package census is 505 files.

## BUG / REGRESSION
The supplied real Android release build reaches `:app:compileReleaseKotlin` and fails in watched-evidence input resolution because `currentEntries` is a `Map<String, String>` but 1.2.2 invokes `firstOrNull` on the Map receiver. The compiler reports unresolved `firstOrNull` and cascading destructuring/type-inference failures. 1.2.3 resolves against `currentEntries.entries` with an explicitly typed entry lambda and a local function returning `String?`.

## DATABASE / USABILITY / CORRECTNESS
Database submission returns a typed result instead of inferring success from message text. A successful response is accepted only when the fixed endpoint returns a lowercase 64-character hexadecimal report ID. The complete ID is shown in bold primary text. Any local validation, serialization, HTTP rejection, successful-HTTP invalid-ID response, or network-request failure produces a bounded diagnostic log and opens a Material 3 Expressive failure dialog. The log uses monospace presentation and can be copied in full through a contained Copy all action; Close is also contained. The title artwork composes the Database glyph with a lower-right red X. The submitted report payload is never copied into the diagnostic log; only bounded operation metadata and the already bounded server response/error are exposed.

## ANDROID PLATFORM
Android 12 is API level 31. VulkanScope 1.2.3 sets `minSdk = 31`, so Android 11/API 30 and older are not installable targets. The legacy `WRITE_EXTERNAL_STORAGE` declaration and pre-Android-10 permission-launch path are removed because they are unreachable and unnecessary at the new minimum. `targetSdk = 37`, the three release ABIs and update-install permission remain unchanged.

## CURRENT UPSTREAM
The authoritative Khronos Registry recheck on 2026-09-12 remains Vulkan Registry 1.4.362 published 2026-09-04. No Vulkan registry/header/query change is introduced. Official Android platform documentation identifies Android 12 as API level 31.

## EVIDENCE
`tools/verify_release_1203.py`, `tools/test_release_1203_state_machine.py` and `tools/test_release_1203_negative_mutations.py` are mandatory. The release verifier must fail immutable 1.2.2 and pass 1.2.3. Negative mutations must reject restoration of the Map receiver compile defect, report-ID truncation, untyped/message-inferred submission outcomes, missing failure dialog/log copy/close behavior, invalid-ID success acceptance, minSdk regression and legacy storage permission restoration while accepting an unrelated permitted wording mutation.
