## Demonstrated defects and requested changes
- `BUG`: the transient network banner could recompute its content from `HIDDEN`, causing a Connected banner to leave using Disconnected presentation.
- `USABILITY`: startup offline state lacked a persistent explanation that internet-only features are unavailable.
- `CORRECTNESS`: internet-only controls needed both actual disabled UI state and execution-time connectivity guards for race-safe Database/update operations.
- `USABILITY`: Turnip selection launched SAF directly and retained only one package; source ZIP provenance was not reliably useful in the installed-driver UI.
- `USABILITY`: shared horizontal filter carousels ended abruptly at the viewport edge.
- `TEST-GAP`: no release-specific behavioral model covered collection-vs-network banner arbitration, bounded multi-driver state, SAF-unavailable fallback selection, persistent provenance privacy or filter-edge state.
