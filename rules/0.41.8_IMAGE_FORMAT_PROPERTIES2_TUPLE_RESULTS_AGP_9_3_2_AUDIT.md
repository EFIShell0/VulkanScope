# VulkanScope 0.41.8 Image Format Properties2 tuple-result / AGP 9.3.2 audit

## Trigger
A live Database comparison showed an older successful `VK_FORMAT_S8_UINT` Android Hardware Buffer Image Format Properties2 row against VulkanScope 0.41.7 `Unknown / Not reported`. 0.41.7 had already made external queries independent from the base query, but only successful tuples were serialized individually. Negative tuple identity was reduced to aggregate counters.

## Root cause
The native `imageFormat2` probe counted `VK_ERROR_FORMAT_NOT_SUPPORTED` and other failures without emitting a detailed property for the exact queried tuple. Downstream UI/TXT/HTML/technicalReport/Database therefore could not distinguish a queried negative result from a tuple that had never been reported.

## Correction
- Successful tuple behavior is unchanged.
- `VK_ERROR_FORMAT_NOT_SUPPORTED` emits `Unsupported: VK_ERROR_FORMAT_NOT_SUPPORTED` under the exact existing Image Format Properties2 tuple key.
- Other failed results emit `Unavailable: VkResult=<numeric>` under that exact tuple key.
- Aggregate diagnostics remain as a coverage summary.
- A dedicated diagnostics row records the fixed query recipe: `VK_IMAGE_TYPE_2D`, transfer-source/transfer-destination/sampled usage and `flags=0`, preventing an exact query result from being overstated as a universal format capability.
- No external-handle query is re-gated on handle-less success.
- The project pins AGP 9.3.2, verified against the current official Android release information, while retaining Gradle 9.7.0.

## State semantics
The query itself completed in both success and `VK_ERROR_FORMAT_NOT_SUPPORTED` cases. The latter is direct evidence that the queried combination is unsupported. Other failures do not prove unsupported capability and remain Unavailable. Unknown is reserved for absence of concrete tuple evidence.

## Compatibility
Submission schema 2 and technicalReport schema 3 remain unchanged. Existing report hashes and stored Database payloads are not rewritten. Historical reports remain comparable and retain their original evidence.
