# VulkanScope 3.0.2 Expressive Loading Compile Audit

## Immutable predecessor and failing-before-fix oracle
- Immutable predecessor: VulkanScope 3.0.1, 801 files, ZIP SHA-256 `eaae03f93ea7c636b8d7bba2e21a871d65349e1ab690cea0dc88bfae5e5cac12`.
- The user-provided `:app:assembleRelease` log is the failing-before-fix oracle. Native builds complete for arm64-v8a, armeabi-v7a and x86_64, then `:app:compileReleaseKotlin` fails at `MainActivity.kt:12564:17` because a Material 3 experimental API is used without the required opt-in.
- Source inspection maps that diagnostic to `LoadingIndicator(color = VulkanAccentSoft)` inside the 3.0.1-extracted top-level `SharedStorageBrowserListing` composable.

## Root cause
- VulkanScope intentionally uses Material 3 Expressive `LoadingIndicator` in several composables and already imports `ExperimentalMaterial3ExpressiveApi`.
- The parent `SharedStorageBrowserDialog` is explicitly opted in, but the newly extracted top-level `SharedStorageBrowserListing` is a separate declaration and does not inherit the parent's opt-in annotation.
- No runtime, Vulkan, storage, input, layout or rendering defect is implicated by this compiler diagnostic.

## Repair
- `SharedStorageBrowserListing` now has an explicit `@OptIn(ExperimentalMaterial3ExpressiveApi::class)` annotation immediately on the top-level composable declaration.
- The existing `LoadingIndicator`, file-manager loading behavior, two-pane landscape layout and all 3.0.1 UI/input behavior remain unchanged.
- Production change relative to 3.0.1 is restricted to that one opt-in annotation line plus release identity in `app/build.gradle.kts`.

## Evidence boundary
- `tools/verify_release_3002.py` verifies release identity, exact opt-in placement, loading-indicator preservation, 3.0.1 UI/input invariants and protected-file hashes.

- `tools/test_release_3002_negative_mutations.py` proves that removing or weakening the required annotation is rejected while a documentation-only mutation remains accepted.
- `tools/verify_release_3002_regression.py` verifies the immutable predecessor census/hash and exact one-line production-source delta.
