## Demonstrated failure

The source imports `androidx.compose.ui.semantics.Role` and uses `Modifier.semantics { role = Role.Button }`, but the predecessor does not import the `androidx.compose.ui.semantics.role` extension property.

## Repair
0.80.12 adds only the missing `androidx.compose.ui.semantics.role` import to production runtime code. Existing button, switch and radio-button role values remain unchanged. Vulkan collection, registry/header data, native code, report serialization, Database submission semantics, Surface behavior, Vulkan Video and Encyclopedia data are not modified.
