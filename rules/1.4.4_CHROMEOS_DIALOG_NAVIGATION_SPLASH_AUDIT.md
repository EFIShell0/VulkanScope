# VulkanScope 1.4.4 ChromeOS, Dialog, Navigation and Splash Audit

Date: 2026-09-25

## Immutable predecessor

- VulkanScope 1.4.3 ZIP SHA-256: `95b0f34218f2a653a2660d0e3597feea50ec05d3193f17e2ff811505d146b9ac`
- Extracted predecessor census: 616 files

## Demonstrated defects and requested changes

- `BUG`: ChromeOS Android Runtime devices were indistinguishable from ordinary Android in the visible/report metadata and the host ChromeOS version could not be represented without guessing.
- `USABILITY`: the shared complex detail dialog retained a portrait-oriented body height cap in landscape, producing a visibly short modal surface.
- `USABILITY`: the custom landscape rail approximated Material 3 instead of using the platform Material 3 navigation rail component, while portrait already used the Expressive short navigation bar.
- `USABILITY`: launch used the default starting window instead of a VulkanScope-branded SplashScreen transition.
- `TEST-GAP`: no release gate tied these four contracts together.

## Current upstream verification

- Android's current ChromeOS guidance documents `PackageManager.hasSystemFeature("org.chromium.arc")` as the platform-detection signal for ChromeOS Android Runtime.
- Current Android adaptive guidance recommends rail-style primary navigation for landscape/desktop-like windows. Material 3 Compose exposes `NavigationRail` and `NavigationRailItem`; VulkanScope portrait already uses `ShortNavigationBar`.
- Android's current SplashScreen guidance requires the SplashScreen API on Android 12+ and recommends the AndroidX compat library for consistent behavior. AndroidX Core SplashScreen 1.2.0 is the current stable splash artifact.
- Khronos latest published Vulkan specification was rechecked as Vulkan 1.4.363 dated 2026-09-18. This release does not silently repin the audited 1.4.362 collector/header/query baseline; the current upstream version and the app's pinned collection baseline are recorded as distinct facts.

## Repair

- ChromeOS ARC is reported explicitly in on-device information, complete TXT/HTML exports and Database device metadata. Host ChromeOS version is deliberately unavailable rather than inferred.
- Expressive detail dialogs fill the available landscape height with bounded margins and keep internal scrolling and a reachable close region.
- Landscape/TV primary navigation uses Material 3 `NavigationRailItem` selected indicators and labels; portrait retains `ShortNavigationBarItem` so both orientations use first-party Material 3 navigation components.
- App launch uses `Theme.SplashScreen`, the packaged VulkanScope foreground logo, AndroidX Core SplashScreen 1.2.0 and a bounded fade/scale exit transition without a second Activity.

## Security, memory, performance and accessibility review

- No permission or endpoint was added.
- ChromeOS detection reads a boolean system feature only. No account, hardware identifier or host filesystem data is collected.
- No native Vulkan query path, handle lifetime, report readiness gate or Surface lifecycle state machine was changed.
- Dialog content remains scrollable and navigation items retain text labels, Material roles and TV focus behavior.
- Splash animation removes the splash provider view at completion and does not retain Activity/context references beyond the animation.
