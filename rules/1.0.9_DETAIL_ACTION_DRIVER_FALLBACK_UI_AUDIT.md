## Demonstrated predecessor failures
The supplied 1.0.8 screenshots show a shared detailed-evidence dialog whose footer can be pushed far enough down that the Extensions Close action is clipped into a small empty pill. They also show inconsistent visual/action hierarchy for chevron-ended cards, uncontained Analysis actions, no explicit System-driver evidence detail surface, no visible long-press selection feedback, and an Analysis Database report-id field that remains editable while offline. The user also requested exact no-SAF names and locations for every remaining import/export path.

These are `BUG`, `USABILITY` and local-state correctness issues. No Vulkan capability query, registry baseline, schema or Database transport defect is claimed.

## Upstream recheck before production editing
On 2026-09-08 the canonical Khronos Vulkan Registry still reports Vulkan 1.4.362 dated 2026-09-04. Android's current storage documentation continues to state that app-specific external directories can be accessed by the owning app without storage permissions and are removed on uninstall, while SAF remains the user-mediated document mechanism. The existing permissionless bounded fallback model therefore remains appropriate and no manifest permission change is required.

## Intended repair boundary
The repair is limited to MainActivity presentation/local UI state, two vector action glyphs, release metadata and verification/audit files. System-driver details are captured only from authoritative completed System evidence and stored only as private UI metadata. No Turnip evidence is relabeled as System evidence. No report/export/Database serialization path reads the private summary.

Detailed dialogs receive an explicit bounded overall height and flexible scroll body so the footer remains visible. Shared icon/text actions use centered 48 dp-class geometry. Large chevron-ended action rows and Overview destination rows become non-clickable surfaces with only the trailing chevron control invoking the action; the existing external-link rows keep their trailing open-external control. Evidence provenance, watch-list insertion and Copy link receive contained icon/text treatments. Long-press evidence rows animate scale/background while held.

Analysis Database report-id entry and Fetch are both offline-gated by the existing validated-network state, with an amber reason. No synchronous HTTP/DNS/socket connectivity probe is added.

The UI spells out no-SAF filename families and roots: Analysis `VulkanScope-*-analysis.json`, minimum `VulkanScope-*-minimum.json`, exported technicalReport `VulkanScope-<GPU>-technicalReport.json`, Turnip `turnip_01.zip`..`turnip_10.zip`, and complete report `VulkanScope-<GPU>-report.txt/.html` or multi-GPU equivalent. App-specific relative roots and public Download behavior are shown without promising a single absolute mount path.
