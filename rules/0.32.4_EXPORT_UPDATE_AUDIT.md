# VulkanScope 0.32.4 export and update audit

- Verified that Vulkan 1.4.360 extension-query feature output enters the shared `features` model and that generated/query properties enter `detailedProperties`.
- TXT export emits both `FEATURES` and every `DETAILED QUERY RESULTS` entry.
- HTML export emits both Features and every Detailed query result entry.
- Structured database submission emits both `features` and `detailedProperties` under every device in `technicalReport`.
- `VK_EXT_cooperative_matrix_maintenance1` matrix component types now include canonical `VkComponentTypeKHR` names plus preserved raw enum values.
- Exact 64-bit format/queue/memory masks remain preserved using additive unsigned-decimal string fields in the structured payload.
- The explicit UpToDate banner duration is 8 seconds; update-available and failure banners retain the previous 10-second duration.
- Update lookup uses the official GitHub Releases API endpoint for `EFIShell0/VulkanScope`, accepts only official GitHub release-asset URLs, bounds response/download size, validates APK package identity, verifies compatible signing certificates, and requires a strictly newer versionCode and versionName before installation.
