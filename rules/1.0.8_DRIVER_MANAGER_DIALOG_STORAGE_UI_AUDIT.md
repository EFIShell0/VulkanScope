## Demonstrated UI and interaction gaps
The supplied 1.0.7 screenshots demonstrate driver-manager duplication, insufficient source emphasis on Overview, inconsistent question/destructive action iconography, external links that resemble in-app navigation, a row-wide Analysis switch target, an amber generic Unknown state, uncontained Analysis history/evidence actions and missing user-visible behavior for Analysis import/export when no SAF provider is available. These are presentation, local-interaction and bounded-local-storage defects; no Vulkan capability-evidence defect is claimed.

## Production repair
Settings uses one `Driver manager` section. The System row is part of that section, exposes a contained Activate action only while inactive and uses the green ACTIVE pill while selected. Overview source labels are bold, with System in primary white and Turnip/third-party in Vulkan accent red. Turnip-ineligible devices still expose only amber Unavailable evidence. Unavailable managed slots retain only Remove and visually de-emphasize/strike their metadata; selected Turnip remains removable through an explicit destructive confirmation that states System fallback.

A shared question-title component supplies the accent-contained question glyph for confirmation dialogs and a shared Cancel action supplies an uncontained normal-weight X. Destructive actions use contained treatment, the history baseline action is contained, Evidence actions has its own contained glyph, and the shared X/label geometry is centered consistently.

Generic Unknown/Unresolved presentation is neutral gray rather than amber. Unavailable stays amber, Available remains blue, Supported/Pass remain green, Incomplete remains purple, Not applicable remains neutral gray and negative/unsupported evidence remains red. This preserves the established VulkanScope semantic-color contract instead of conflating availability with support.

External web destinations use the open-external glyph. Khronos specification actions are contained. GitHub and Database Info rows are non-clickable informational surfaces with only the trailing external icon button invoking browser navigation. Existing right chevrons continue to mean in-app navigation.

Analysis SAF fallback is explicit and local. With no suitable system document provider or a failed picker launch, bounded imports search only VulkanScope-named JSON files in app-specific exchange roots; bounded exports write to canonical app-specific exchange storage with private internal fallback. The UI discloses fallback scope, no broad permission and uninstall lifetime. Complete TXT/HTML report export retains its existing public Downloads fallback and now states that behavior explicitly. Turnip fallback remains the existing exact-name app-specific review workflow.

## Non-regression boundary
No AndroidManifest permission, native Vulkan, Registry/header/generated query, AdvancedAnalysis, report serialization, Database schema/endpoint, ABI or dependency change is part of 1.0.8. Runtime changes are limited to MainActivity and the three new vector resources required by the requested UI.
