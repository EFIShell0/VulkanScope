# VulkanScope 0.41.6 Kotlin Compile Fix Audit

Release target: VulkanScope 0.41.6 / versionCode 416.

## Confirmed build failure

The supplied `assembleRelease` log reached `:app:compileReleaseKotlin` after native compilation completed for arm64-v8a, armeabi-v7a and x86_64. Kotlin then failed at the Analysis dependency-graph depth state because `mutableIntStateOf` was referenced without importing `androidx.compose.runtime.mutableIntStateOf`.

## Fix

- Added the required Compose runtime import.
- Kept `mutableIntStateOf(4)` rather than replacing it with boxed `mutableStateOf(4)`.
- Added release-verifier checks for primitive Compose state factories so this import class of compile regression is release-blocking.
- Bumped application identity to 0.41.6 / 416.

## Scope

No Vulkan query, report schema, Analysis evidence semantics, Database payload, network behavior, ABI, native ownership or security policy is changed by this patch.

## Native warnings

The libadrenotools diagnostics in the supplied build log are warnings emitted by the third-party dependency. They occur before Kotlin compilation and did not stop the supplied build. They are not suppressed or misclassified as the cause of this release failure.
