# VulkanScope 0.41.5 Analysis, Profile and Database Compatibility Audit

Release target: VulkanScope 0.41.5 / versionCode 415.

## Scope

The Analysis workspace was re-audited across snapshot import/export and diffing, Profile/Minimum evaluation, dependency graph, watched evidence, heuristic diagnostic evidence, Database sharing and optional isolated self-tests. The audit also checks compatibility with the current VulkanScope Database contract.

## Correctness changes

- Snapshot coverage was expanded to canonical query, memory, queue/video, layer, Surface/safety, Profile, Display/HDR and registry evidence.
- Canonical pre-0.41.5 snapshot keys remain the primary keys; only actual duplicate rows receive deterministic duplicate suffixes instead of implicit JSONObject replacement.
- Device-extension and Surface-format removal regression candidates require current completeness evidence.
- Profile API comparison is major.minor.patch aware.
- Profile absence under incomplete device-extension enumeration remains UNKNOWN.
- Promoted-to-core satisfaction uses checked-in registry metadata.
- Numeric minimum and maximum-direction checks are distinct.
- Partial Profile coverage remains UNKNOWN and is not presented as full profile PASS.
- Optional self-tests target the selected physical device and do not silently fall back to the first device.

## Usability and performance

- Compare exposes state and evidence-kind filters.
- Profile evaluation exposes search and PASS/FAIL/UNKNOWN filters.
- Dependency graph depth is selectable from 1–4.
- Watched evidence exposes Matched/Missing filtering and bounded previews without collecting an unbounded match list.
- Expensive Analysis computations are kept outside LazyListScope and tab-scoped where practical.
- Database permalinks use the current canonical hash route.

## Safety and ownership

Snapshot bounds remain 8 MiB / 32768 entries with bounded key/value lengths. Optional Vulkan test objects retain deterministic cleanup. Static ownership review found no new unmatched Vulkan/JNI resource lifetime introduced by this release; static review is not claimed as proof of zero real-device leaks or crashes.

## Specification baseline

The current published Vulkan specification remains Vulkan 1.4.360 dated 2026-08-14. Current Vulkan Profiles sources include Android 17/16/15 requirements, Android Vulkan Profile 2025 and Roadmap 2026. The lightweight evaluator intentionally reports UNKNOWN when it cannot prove the complete official profile requirement universe.
