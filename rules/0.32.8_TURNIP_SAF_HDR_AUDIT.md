# VulkanScope 0.32.8 Turnip SAF and HDR audit

- Replaced the 0.32.7 ACTION_GET_CONTENT Turnip importer with AndroidX ActivityResultContracts.OpenDocument, which maps to the system ACTION_OPEN_DOCUMENT flow.
- This follows Android's documented SAF file-open flow and AOSP DocumentsUI picker behavior, which explicitly avoids inline-opening archive containers when selecting a document.
- The picker requests application/zip, application/x-zip-compressed and application/octet-stream and remains protected by the existing in-flight guard.
- Post-selection ZIP content validation remains authoritative; MIME type does not establish trust.
- Fixed duplicated decompressed-byte accounting in Turnip ZIP extraction.
- Added local HDR logo cards aligned with VulkanScope Database presentation. Logos never infer capability support.
- Database schema-v3 producer data is unchanged and remains compatible with VulkanScope Database 0.34.7.

- Corrected Android API 37 HLG+ mapping to the official value 6; the previous value 5 mapping was incorrect.
