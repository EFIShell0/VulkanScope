# VulkanScope 0.32.7 Turnip SAF and Database audit

- Replaced the broad `OpenDocument` ZIP selection path with a dedicated SAF `ACTION_GET_CONTENT` contract limited to `application/zip`, `application/x-zip-compressed` and `application/octet-stream`.
- Removed the `*/*` MIME fallback that can let archive-aware document providers enter a ZIP as a virtual directory rather than return the ZIP URI.
- Added a picker in-flight guard so the Activity Result launcher cannot be invoked twice while the first SAF request is pending.
- Existing post-selection security validation remains authoritative: bounded extraction, zip-slip prevention, required `meta.json`, schema version 1, safe metadata-declared `.so` filename, canonical private path and non-empty library validation.
- Re-audited the schema-v3 producer against Database 0.34.4: Display/HDR, layer extensions, exact U64 masks, queue video/optical-flow/data-graph fields, Surface diagnostics and Vulkan 1.4.360 coverage metadata are already emitted and require no schema-breaking change.
