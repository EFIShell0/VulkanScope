# VulkanScope 0.41.1 Analysis Compose Build-Fix Audit

Release target: VulkanScope 0.41.1 / versionCode 411.

## User build evidence

The 0.41.0 release build completed native C++ compilation for arm64-v8a, armeabi-v7a and x86_64, then failed in `compileReleaseKotlin` because `remember(...)` was invoked directly from `LazyListScope` and watched evidence retained `Map.Entry` objects while consuming them as pairs.

## Fixes

- Hoisted diff, profile, dependency-graph, visual-node, diagnostic-score, watched-evidence and share-link state calculations to `AnalysisPage` composable scope.
- Converted watched evidence matches to explicit `Pair<String, String>` values before lazy rendering.
- Preserved bounded graph traversal, lazy list rendering, local-only analysis state and all 0.41.0 capability/report semantics.
- Kept Material 3 Expressive opt-in at the Analysis composable scope.

## Non-regression

- Native Vulkan collection is unchanged.
- Target ABIs remain arm64-v8a, armeabi-v7a and x86_64.
- Canonical Database schema remains schema 2 / technicalReport 3.
- Vulkan baseline remains 1.4.360.
- Update, Turnip/SAF, report completeness and native safety hardening remain unchanged.
