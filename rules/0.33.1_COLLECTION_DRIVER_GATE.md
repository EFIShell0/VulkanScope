# VulkanScope 0.33.1 collection driver gate

The Turnip/SAF implementation remains the fully restored 0.32.4 path from 0.33.0. This release changes only Settings interactivity while a complete Vulkan collection is in progress.

- System driver selection: disabled until complete collection.
- Turnip driver selection: disabled until complete collection, then additionally governed by normal Turnip eligibility.
- Turnip ZIP import: disabled until complete collection.
- TXT, HTML and Database report actions retain their existing complete-report gate.
- No picker, ZIP parser, library discovery, native loader or probe-service behavior is changed.
